# UWork 0.1.4

此发布候选在公开前失败，未分发安装包；请使用包含同一批修复和发布门禁修正的 0.1.5。

## 修复

- 修复任务“查看调用轨迹”为空的问题；支持窄窗口展示及长轨迹搜索定位。
- 修复新任务提交停留在草稿的问题，官方插件仅收集必要运行依赖。
- 修复日志、MCP 配置与会话库路径不一致的问题。
- 保留 Windows 旧版 `os.homedir()` 的 USERPROFILE 优先语义；HOME 与 USERPROFILE 不同时，也能正确定位旧库和显式 `~/` 会话库。

## 升级与数据迁移

- 首次启动自动将可确认属于 UWork 的旧默认会话库迁移到当前 UWork 数据根，保留历史内容与续聊上下文。无需手动复制数据库；显式配置的会话库路径保持优先。
- 原会话库保留。迁移会包含已提交的 WAL 数据，校验后才开放任务；冲突、归属不明或其他旧实例仍在写入时显示错误，不会以空库替代历史。
- 移动整个数据目录改为下次启动时执行。保存计划后仍可继续工作；重启时停写、复制并校验，成功后切换。未提交的失败计划可以取消并继续使用原目录。
- 同步修复冷启动退出、过期取消、跨窗口设置刷新等边界。

遇到迁移错误请保留原目录，关闭旧 UWork/Agent 实例后重试。保留旧库用于恢复；升级后的新增数据不会自动同步回旧版本。远端持库服务及独立 CLI 不会随桌面升级自动改写其会话库。
