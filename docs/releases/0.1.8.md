# UWork 0.1.8

## 修复与改进

- 企业 HMAC 手机远控在身份校验窗口内复用同一配对读取工作区信息，最多四轮、每轮三秒；超时耗尽后结束，避免重配对撤销刚完成的授权或重复整组重试。
- 关闭版本导航时仍检查请求代际，断连、换设备和释放后到达的旧响应或错误不会写入当前工作区状态。
- 默认版本导航继续校验当前页面 URL，移除全局历史版本缓存旁路；单一网页构建可通过部署开关显式关闭导航。
- 设备目录对网络错误、HTTP 429 和 5xx 做有限重试，认证和权限错误立即交给上层处理。
- 修复 CI 中 Electron 首次导入触发并发安装、解压目录冲突的问题，在并行测试和各平台原生构建前串行准备固定版本的真实 Electron。
- 微盘固定出口探测增加脱敏的阶段与错误分类，区分出口查询、企业微信 API、HTTP、超时和网络故障，保留失败停止与临时配置清理。

## 部署说明

- 自托管只分发单一手机网页构建时，构建时设置 `VITE_ZCODE_WEB_REMOTE_CONTROL_VERSION_GUARD=off`；默认仍开启版本导航。
- 手机网页代码需要同步部署到既有网页服务。桌面安装包不会自动部署网页、企业控制面或 relay；真机首连/续连效果仍以目标环境验收为准。
- Release 提供 macOS ARM64、Windows x64、Linux x64/ARM64 四个目标；macOS 使用 ad-hoc 签名，未经过 Apple 公证。
