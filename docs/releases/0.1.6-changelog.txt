UWork 0.1.6 更新内容

【主要功能变更】

✅ 修复 Windows 环境下草稿会话创建失败问题
   - 添加数据库打开和迁移的重试机制
   - 解决文件系统延迟释放锁导致的错误
   - 提升 Windows 和 Linux（NFS、容器环境）下的健壮性

✅ 改进错误提示
   - 提供更详细的错误信息和诊断建议
   - 显示具体的错误类型（database_locked）

【升级建议】

如果在 0.1.5 版本遇到"草稿会话创建失败"错误：
1. 升级到 0.1.6 版本
2. 确保关闭所有旧的 UWork 实例
3. 重新启动应用

本版本与 0.1.5 完全兼容。
