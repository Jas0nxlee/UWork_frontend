## 本次更新

- UWork 首个正式版本定为 `0.1.0`，登录页、安装包和 Release 使用统一版本号。此前源码中的 `0.10.0` 未公开发布；上游 CLI 与插件保留独立版本。
- 支持企业微信多组织登录，安装包通过发布配置内置北京、南京、厦门、天津四家组织的公开登录参数；应用 Secret、用户 Token 和模型密钥不随安装包分发。登录后沿用企业网关、模型配置、套餐及用量能力。
- 保留桌面工作区、远程工作区 / Source Server、Office 预览与编辑、插件及 Bot/IM 通道。机器人通道管理入口调整到侧栏底部。
- 移除手机/浏览器远控客户端、Android 壳、桌面远控宿主及配对入口；独立中继服务端与共享协议合同保留。
- 修复远控裁剪后本地标签恢复和关闭时没有更新桌面实时订阅范围的问题，保留跨窗口任务同步。
- 更新开发指令、使用手册与第三方图标材料路径，清理裁剪后残留的未使用符号。

## 安装与验证

- 提供 macOS arm64/x64、Windows x64、Linux x64/arm64 安装包；各文件的 SHA-256 记录在 `SHA256SUMS`。
- 继续使用 `~/.uwork` 用户数据，不迁移或删除上游 `~/.zcode`。已安装其它版本的用户可手工下载安装，保留原数据目录。
- 企业微信公开参数在构建和打包后校验；各公司真实扫码、企业后台权限与外部集成仍需按实际环境验收，不以构建通过替代企业验收。
