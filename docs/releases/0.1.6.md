# UWork 0.1.6

## 修复

- **修复 Windows 环境下草稿会话创建失败问题**：添加数据库打开和迁移的重试机制，解决文件系统延迟释放锁导致的"草稿会话创建失败"错误
- **改进错误提示**：当草稿会话创建失败时，提供更详细的错误信息和诊断建议
- **提升跨平台健壮性**：重试机制同时适用于 Windows 和 Linux（NFS、容器环境）下的数据库锁竞争场景

## 技术改进

- 在会话数据库打开时添加最多 10 次的指数退避重试（200ms ~ 2000ms）
- 在数据库快照（snapshot）操作中添加锁重试逻辑
- 数据库锁错误现在会显示具体的错误类型（`database_locked`）和用户指引

## 升级建议

如果在 0.1.5 版本遇到"草稿会话创建失败"错误：
1. 升级到 0.1.6 版本
2. 确保关闭所有旧的 UWork 实例
3. 重新启动应用

本版本与 0.1.5 完全兼容，数据库迁移逻辑保持不变。
