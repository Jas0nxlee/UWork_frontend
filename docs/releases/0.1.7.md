# UWork 0.1.7

## 新增与改进

- 恢复手机远控相关客户端、网页和 Android 壳工程，提供企业微信工作台设备列表与连接流程，以及切换设备、返回任务和退出登录等交互。
- 企业远控准入增加组织与成员身份校验；配对身份帧先于业务消息处理，设备目录和配对应答材料按企业身份隔离。
- 接入 models.dev，自动补全模型上下文、最大输出、输入类型和明确的推理档位。参数逐字段采用“手动配置 → 网关下发 → models.dev → 应用内置”的优先级。
- 支持显示文本、图片、音频、视频和 PDF 输入能力，保留手动覆盖、模型启停、排序及原始请求 ID。
- 内置 UCAS 六个逻辑型号对应的离线参数：Claude Sonnet 5.5、Claude Haiku 5.5、Kimi K3.1 Pro、GLM-5.3，以及两个 DeepSeek Flash 1017 别名。
- 按配置要求，为 `ucas-deepseek-flash` 补齐文本、图片、PDF、结构化输出和原生联网搜索默认能力。

## 修复

- 修复跨源重定向中自定义敏感请求头的保护问题，将受影响的 follow-redirects 精确升级到 1.16.2；生产依赖审计高危和严重项均为 0。
- 企业远控授权绑定当前终端；终端替换、企业退出或切换用户时撤销旧连接，旧异步校验结果不能放行新终端。
- 修复企业注销事件先于共享凭据清理提交的时序问题，提交后再次通知并重读权威身份，避免旧连接残留。

- 修复仅返回模型 ID 的网关名单套用统一固定参数，导致不同模型的上下文、输入类型和推理档位不准确的问题。
- 已有模型重新获取时，即使没有新增成员，也会更新自动能力；手动设置保持优先。
- 目录缓存与供应商端点分别绑定；目录请求失败、切换连接、过期结果或关闭 Host 时，避免把旧结果写入当前配置。
- 明确不适用于文本聊天的模型仍可查看，但不会进入聊天模型选择和聊天连通性测试。
- 优化远控页面、企业工作台入口和 UWork 品牌显示的一致性。
- 修正合并后第三方图标清单的来源路径，确保声明与实际共享资源一致。

## 升级与部署说明

- 模型目录会后台补齐已保存模型的自动参数；未匹配到目录时继续使用软件内置值，已有手动配置仍优先。
- 企业微信远控入口需要配套后台、独立 relay、同源网页和企业微信授权域名配置。本次客户端发布不代表这些服务已部署完成；真实企业微信手机全链路仍需管理员在目标环境验收。
- Android 壳工程随源码提供，本次 Release 的构建合同仍是四个桌面目标，不包含独立 Android APK。
- 音频标记用于模型能力配置，本次未新增音频附件发送。原生联网搜索默认值属于能力声明，本次不以勾选显示代替服务端搜索执行验收。
