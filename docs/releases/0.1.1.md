## 安装与兼容

- GitHub 保留 macOS arm64/x64、Windows x64、Linux x64/arm64 全部构建和校验产物；摘要见 `SHA256SUMS`。
- GitLab 下载文件为 `UWork-0.1.1-mac-arm64.zip`、`UWork-0.1.1-win-x64.zip`、`UWork-0.1.1-linux-x64.zip`。Ubuntu 可继续通过 GitHub 的 DEB 安装，ZIP 解压后运行应用可执行文件。
- 继续使用 `~/.uwork`，不迁移或删除上游 `~/.zcode`。保留既有协议、应用标识、服务地址和工作区配置文件约定。
