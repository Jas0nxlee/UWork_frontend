# UWork 0.1.9

## 修复

- 修复部分 Windows 用户从旧版本升级后无法创建草稿会话的问题。旧安装遗留的空组件目录不再中断插件加载，可正常新建会话和发送消息。
- macOS 与 Linux 使用相同的插件加载修复；继续校验当前组件所需资源，不改变历史会话和模型配置。
- 发布 CI 增加升级残留目录回归检查，防止同类问题再次进入安装包。

## 升级与验证

- Windows 虚拟机已验证 0.1.2、0.1.5、0.1.6 升级到修复候选后，旧消息可见，新会话能够收到模型回复。0.1.2 升级到原版 0.1.8 的失败场景已复现。
- macOS ARM64 已在隔离资源副本中复现相同加载错误，并验证修复；未进行旧版 Mac 安装包逐版本完整升级。详细范围见 [升级验证记录](https://github.com/Jas0nxlee/UWork_frontend/blob/v0.1.9/docs/testing/windows-upgrade-0.1.9.md)。
- Release 沿用 macOS ARM64、Windows x64、Linux x64/ARM64 四个目标。macOS 使用 ad-hoc 签名，未经过 Apple 公证。
