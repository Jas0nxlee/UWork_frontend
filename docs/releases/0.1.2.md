## 本次更新

- 修复任务运行中通过侧栏、快捷键或新建菜单创建项目外任务时无响应的问题。多个入口共用草稿生命周期；旧草稿目录缺失时创建新草稿，避免复用已经发送的任务目录。
- 演示文稿、文档、PDF 和电子表格官方插件的 `visual-judge` 默认继承主任务模型，避免固定引用某个账号的模型而导致子智能体无法启动。
- 子智能体设置明确区分“继承主任务模型”与“使用插件默认”。显式选择继承后，可覆盖插件自带的固定模型；重新进入设置仍正确回显。
- 修复显式用户目录与默认目录生成不同设备身份的问题，统一使用 UWork 数据根下的同一份身份文件。
- 修复 MCP 在首次授权目录尚未创建时失败的问题，以及并发授权、刷新和迟到 401 可能重复刷新或授权的问题；保留凭据代际、锁和 issuer 校验。
- 修复历史任务取消记录的恢复显示，兼容既有停止消息和当前 UWork 停止消息。

## 安装与兼容

- GitHub 提供 macOS Apple Silicon / Intel、Windows x64、Linux x64 / ARM64 全部安装格式，大小和摘要见随版清单与 `SHA256SUMS`。
- GitLab 自动分发 `UWork-0.1.2-mac-arm64.dmg`、`UWork-0.1.2-win-x64.exe`、`UWork-0.1.2-linux-amd64.deb`，只上传安装包，不同步源码。
- 继续使用 `~/.uwork`，不迁移或删除上游 `~/.zcode`。本版不恢复已退役的内置模型账号登录；MCP OAuth 授权继续受支持。
